* Fr1

** Loop-termination

For every loop-invariant proof, state that loop *terminates*, and the invariant (at termination). Initialisation -> maintainance -> termination.

** No $O/\Theta$ in an induction hypothesis

In induction hypothests write $t(n) \leq cn\lg(n)$ with an *explicit named constant*, never $t(n) \leq O(n\lg(n))$. The reason is that in Landau notation, constant is allowed to change, in each at every level of recursion, so the *proof* proves nothing.

** Watershed procedure

For any $T(n) = aT(\dfrac{n}{b}) + f(n)$, extract $a$ and $b$, and compute $w(n) = n^{\log_{b}(a)}$, then compare.

** $\mathbb{Z}_{p}$ field caveat

In a field, only nonzero elements have multiplicative inverses, an $1 \neq 0$ (so a field has at least 2 elements).

* Fr2

** Master Theorem

Let $a > 0, b > 1$ be constants. Let $f(n) \ge 0$ be the driving function. Define recurrence $T(n)$ on $n \in \mathbb{N}$ by:

$$T(n) = a T(\frac{n}{b}) + f(n)$$

such that:

$$aT(\frac{n}{b}) = a'T(\lfloor \frac{n}{b} \rfloor) + a''T(\lceil \frac{n}{b} \rceil)\ :\ a', a'' \ge 0,\ a = a' + a''$$

1. If $\exists \epsilon > 0 : f(n) = O(n^{\log_b(a - \epsilon)})$, then $T(n) = \Theta(n^{\log_b(a)})$

2. If $\exists k \ge 0 : f(n) = \Theta(n^{\log_b(a)} \lg^{k}(n))$, then $T(n) = \Theta(n^{\log_b(a)} \lg^{k+1}(n))$

3. If $\exists \epsilon > 0 : f(n) = \Omega(n^{\log_b(a + \epsilon)})$, and $af(\frac{n}{b}) < cf(n)$ for $c < 1$ and $\forall$ sufficienlty large $n$, then $T(n) = \Theta(f(n))$

** Problem 18

- $T(n) = 2T\!\left(\dfrac{n}{4}\right) + \Theta(1)$

  \begin{align*}
  f(n) &= \Theta(1) \\
  w(n) &= n^{\log_4(2)} \\
       &= n^{1/2} \\
  \frac{f(n)}{w(n)} &= \frac{\Theta(1)}{n^{1/2}} = \Theta(n^{-1/2}) = O(n^{-\varepsilon}),\ \varepsilon = \frac{1}{2} \to \text{case 1} \\
  \therefore T(n) &= \Theta(n^{1/2})
  \end{align*}

- $T(n) = 2T\!\left(\dfrac{n}{4}\right) + \Theta(\sqrt{n})$

  \begin{align*}
  f(n) &= \Theta(\sqrt{n}) \\
  w(n) &= n^{\log_4(2)} \\
       &= n^{1/2} \\
  \frac{f(n)}{w(n)} &= \frac{\Theta(\sqrt{n})}{n^{1/2}} = \Theta(1) \to \text{case 2} \\
  \therefore T(n) &= \Theta(n^{1/2}\lg(n))
  \end{align*}

- $T(n) = 2T\!\left(\dfrac{n}{4}\right) + \Theta(\sqrt{n} \lg^2 n)$

  \begin{align*}
  f(n) &= \Theta(n^{1/2} \lg^2(n)) \\
  w(n) &= n^{\log_4(2)} \\
       &= n^{1/2} \\
  \frac{f(n)}{w(n)} &= \frac{\Theta(n^{1/2} \lg^2(n))}{n^{1/2}} = \Theta(\lg^2(n)) \to \text{case 2} \\
  \therefore T(n) &= \Theta(n^{1/2} \lg^{3}(n))
  \end{align*}

- $T(n) = 2T\!\left(\dfrac{n}{4}\right) + \Theta(n)$

  \begin{align*}
  f(n) &= \Theta(n),\ \text{take } g(n) = n \\
  w(n) &= n^{1/2} \\
  \frac{f(n)}{w(n)} &= \Theta\!\left(\frac{n}{n^{1/2}}\right) = \Theta(n^{1/2}) = \Omega(n^{\varepsilon}),\ \varepsilon = \tfrac{1}{2} \to \text{case 3} \\

  \therefore T(n) &= \Theta(n)
  \end{align*}

- $T(n) = 2T\!\left(\dfrac{n}{4}\right) + \Theta(n^2)$

  \begin{align*}
  f(n) &= \Theta(n^2),\ \text{take } g(n) = n^2 \\
  w(n) &= n^{1/2} \\
  \frac{f(n)}{w(n)} &= \Theta(n^{3/2}) = \Omega(n^{\varepsilon}),\ \varepsilon = \frac{3}{2} \to \text{case 3} \\
  2g(\frac{n}{4}) &= \frac{n^2}{8} = \frac{1}{8} g(n),\ c = \frac{1}{8} < 1 \\
  \therefore T(n) &= \Theta(n^2)
  \end{align*}

** exam_01 Q1

*** Task

Bubblesort works by repeatedly swapping adjacent elements that are out of order. The procedure is

#+begin_src text
1: procedure BUBBLESORT(A, n)
2:     for i = 1 to n - 1 do
3:         for j = n downto i + 1 do
4:             if A[j] < A[j-1] then
5:                 exchange A[j] with A[j - 1]
6:             end if
7:         end for
8:     end for
9: end procedure
#+end_src

(a) (1 point)

Let $A'$ denote the array $A$ after =BUBBLESORT(A, n)= is executed. To prove that =BUBBLESORT= is correct, you need to prove that it terminates and that

$$A'[1] \le A'[2] \le \cdots \le A'[n].$$

In order to show that =BUBBLESORT= actually sorts, what else do you need to prove?

(b) (3 points)

State a precise loop invariant for the =for j = n downto i + 1= loop in lines 3--7 and prove that it holds.

(c) (2 points)

Using the termination condition of the loop invariant stated and proved above, state a loop invariant for the =for i = 1 to n - 1= loop in lines 2--8 that allows you to prove the inequality above for the $A'$ array.

(d) (2 points)

Prove that the loop invariant above holds and conclude that =BUBBLESORT= works.

*** (a)

That the $A^{\prime}$ is a permutation of $A$.

*** (b)

*Invariant.* At the start of each iteration of the loop in lines 3-7: $A[j] \leq A[k]\ \forall j \leq k \leq n$.

*Initialisation.* $j = n$: $A[n] \leq A[n]$, holds trivially.

*Maintenance.*

Let $A$, $B$ be the array before and after the iteration $j$.

Lines 4-6 make: $B[j-1] = \min(A[j-1], A[j])$, $B[j] = \max(A[j-1], A[j])$, $B[k] = A[k]$ otherwise.

So $B[j-1] \leq B[j]$, and $B[j-1] \leq A[j] \leq A[k] = B[k]\ \forall j+1 \leq k \leq n$ by the invariant.

Hence, $B[j-1] \leq B[k]\ \forall j-1 \leq k \leq n$.

*Termination.* $j = i$: $A[i] \leq A[k]\ \forall i \leq k \leq n$.

*Remark.* The loop only swaps $A[j-1]$ and $A[j]$, with $j - 1 \geq i$, so it permutes $A[i \ldots n]$, leaving $A[1 \ldots i-1]$ untouched.

*** (c)

*Invariant.*
1. $A[1] \le \dots \le A[i-1] \le A[k]\ \forall\, i \le k \le n$
2. $\mathrm{perm}(A, A_1)$

*** (d)

*Invariant.* At the start of each iteration of the loop on lines 2-8: $A[1] \leq \ldots \leq A[i - 1] \leq A[k]\ \forall i \leq k \leq n$

*Initialisation.* $i = 1$: $A[1 \ldots 0]$ is empty, thus holds trivially.

*Maintenance.*

Let $A$, $B$ be the array before and after the iteration with index $i$.
1. $B[1 \ldots i-1] = A[1 \ldots i-1]$ (remark), so $B[1] \leq \ldots \leq B[i-1]$ (invariant).
2. $B[i \ldots n]$ is a permutation of $A[i \ldots n]$ (remark), so $B[i-1] = A[i-1] \leq B[k]\ \forall k \geq i$ (invariant; vacuous for $i = 1$).
3. $B[i] \leq B[k]\ \forall k \geq i$ (termination of (b)).

Hence $B[1] \leq \ldots \leq B[i-1] \leq B[i] \leq B[k]\ \forall k \geq i+1$, i.e. the invariant for $i+1$.

*Termination.* $i = n$: $A[1] \leq \ldots \leq A[n - 1] \leq A[n]$.

*Conclusion.* Both loops have fixed bounds, so =BUBBLESORT= terminates. At exit $A = A^{\prime}$, so $A^{\prime}$ is sorted. By the remark, every inner loop only permutes $A$, so $A^{\prime}$ is a permutation of the input. Hence =BUBBLESORT= sorts.

*** Task

Describe what a heap is and what it is usually used for. Especially, talk about the following points:

(a) Explain how a heap is represented in an array.

(b) Describe the algorithms =MIN-HEAPIFY= and =BUILD-MIN-HEAP= for constructing a min heap.

(c) Explain which algorithms are needed to turn a min heap into a min priority queue, and describe the algorithm =MIN-HEAP-DECREASE-KEY=.

(d) What are the running times of =MIN-HEAPIFY= and =MIN-HEAP-DECREASE-KEY=?

*** (a)

A min-heap is a nearly complete binary tree satisfying the min-heap property:

$A[\mathrm{Parent}(i)] \leq A[i]$ for every non-root $i$, so the minimum is at the root.

Heaps are used for priority queues and heapsorts.

*** (b)

=MIN-HEAPIFY(A, i)=: assumes the subtrees rooted at $\mathrm{Left}(i)$ and $\mathrm{Right}(i)$ are min-heaps. Finds the smallest of $A[i]$ and its children; if it is a child, swaps it with $A[i]$ and recurses on that child.

=BUILD-MIN-HEAP(A)=: calls =MIN-HEAPIFY= for $i = \lfloor n/2 \rfloor$ down to $1$ (non-leaf nodes); the backwards order guarantees both child subtrees of $i$ are min-heaps when $i$ is processed.

*** (c)

A min-priority queue needs four operations on top of the heap:

1. =MIN-HEAP-MINIMUM=: return $A[1]$.
2. =MIN-HEAP-EXTRACT-MIN=: return $A[1]$, move $A[n]$ to $A[1]$, decrease $n$, call =MIN-HEAPIFY(A, 1)=.
3. =MIN-HEAP-DECREASE-KEY(A, i, key)=: lower $A[i]$ to $key$ (below).
4. =MIN-HEAP-INSERT(A, key)=: increase $n$, set $A[n] = \infty$, call =MIN-HEAP-DECREASE-KEY(A, n, key)=.

=MIN-HEAP-DECREASE-KEY(A, i, key)=: requires $key \le A[i]$. Set $A[i] = key$. The children were already $\ge$ the old key, so only the parent can violate the min-heap property. While $i > 1$ and $A[\mathrm{Parent}(i)] > A[i]$: swap $A[i]$ with $A[\mathrm{Parent}(i)]$, set $i = \mathrm{Parent}(i)$.

*** (d)

Both are $O(\log n)$. A heap with $n$ elements has height $\lfloor \log_2 n \rfloor$. Each step does $O(1)$ work and moves one level: =MIN-HEAPIFY= moves down, =MIN-HEAP-DECREASE-KEY= moves up.
