- $T(n) = 9T\left(\frac{n}{3}\right) + n^{2}$

  \begin{align*}
  f(n) &= n^2 \\
  w(n) &= n^{\log_3(9)} = n^{2} \\
  \frac{f(n)}{w(n)} &= \frac{n^2}{n^2} = 1 = \Theta(\lg^{k}(n)),\ k = 0 \to \text{case 2} \\
  \therefore T(n) &= \Theta(n^2 \lg(n))
  \end{align*}

- $T(n) = 8T\left(\frac{n}{2}\right) + n^{3}\lg n$

  \begin{align*}
  f(n) &= n^3 \lg(n) \\
  w(n) &= n^{\log_2(8)} = n^3 \\
  \frac{f(n)}{w(n)} &= \frac{n^3 \lg(n)}{n^3} = \lg(n) = \Theta(\lg^{k}(n)),\ k = 1 \to \text{case 2} \\
  \therefore T(n) &= \Theta(n^{3} \lg^{2}(n))
  \end{align*}

- $T(n) = 3T\left(\frac{n}{9}\right) + n^{1/2}$

  \begin{align*}

  \therefore T(n) &= \Theta(n^{1/2} \lg(n))
  \end{align*}

** CLRS 15.3 notes

*** Huffman codes

\[ B(T) = \sum_{c \in C} c.freq \cdot d_r(c) \]
Where:

- $T$ :: a character tree

- $B(T)$ :: total number of bits in a file, also called the *cost* of the tree $T$.

- $C$ / $c$:: the alphabet / the character

- $c.freq$ :: frequency of the character in file

- $d_{r}(c)$ :: how deep in tree is the character

*** Constructing a Huffman code

#+begin_src julia :results output
let
    struct Node
        char::Char
        freq::Int
        left::Union{Node,Nothing}
        right::Union{Node,Nothing}
    end

    Node(c::Char, f::Int) = Node(c, f, nothing, nothing)

    function extract_min!(Q)
        i = argmin(map(q -> q.freq, Q))
        return popat!(Q, i)
    end

    function huffman(C)
        n = length(C)
        Q = copy(C)
        for i in 1:(n-1)
            x = extract_min!(Q)
            y = extract_min!(Q)
            z = Node('\0', x.freq + y.freq, x, y)
            push!(Q, z)
        end
        return extract_min!(Q)
    end

    function printcodes(t, code="")
        if t.left === nothing
            println(t.char, ": ", code)
        else
            printcodes(t.left, code * "0")
            printcodes(t.right, code * "1")
        end
    end

    C = [Node('a',45), Node('b',13), Node('c',12), Node('d',16), Node('e',9), Node('f',5)]
    printcodes(huffman(C))
end

*** Addition

The running time of Huffman's algorithm depends on how the min-priority queue $Q$ is implemented. If $Q$ is binary min-heap, knowing that =huffman='s for loop executes exactly =n-1= times, the loop contributes $O(n\lg(n))$ (with each heap operation running $O(\lg(n))$).

** Huffman's correctness

*** Notation

$d_T(c)$ is the depth of leaf $c$ in $T$, i.e. the length of the codeword of $c$, and

\[ B(T) = \sum_{c \in C} c.\mathit{freq} \cdot d_T(c) \]

Two codewords have equal length and differ only in the last bit if and only if their leaves are siblings.

*** Lemma 15.2 (greedy choice)

If $x, y \in C$ have the lowest frequencies, then $\exists$ an optimal tree $T$ in which $x, y$ are sibling leaves of maximum depth.

*(E) Swap.* Let $T_{u \leftrightarrow v}$ be $T$ with leaves with only $u, v$ being swapped. Thus


\begin{align*}
B(T) - B(T_{u \leftrightarrow v}) &= u.freq \cdot d_T(u) + v.freq \cdot d_T(v) \\
                                  &\quad - (u.freq \cdot d_T(v) + v.freq \cdot d_T(u)) \\
                                  &= (v.freq - u.freq)(d_T(v) - d_T(u))
\end{align*}

Hence, $v.freq \geq u.freq \text{ and } d_{T}(v) \geq d_{T}(u) \implies B(T) \geq B(T_{u \leftrightarrow v})$

*Proof.*

1. WLOG $T$ is full. Let $T$ be optimal, and $x.freq \leq y.freq \leq c.freq \quad \forall c \in C \setminus \{x, y\}$

2. Let $a$ be a leaf of maximum depth $D$.

3. Let $T^{\prime} \coloneqq T_{x \leftrightarrow a}$. Since $x.freq \leq a.freq$ and $d_T(x) \leq d_T(a)$, by (E) $B(T^{\prime}) \leq B(T)$. Denote $b$ a sibling of leaf $x$ in $T^{\prime}$.

4. Let $T^{\prime \prime} \coloneqq T^{\prime}_{y \leftrightarrow b}$. Since $y.freq \leq b.freq$ and $d_{T^{\prime}}(y) \leq d_{T^{\prime}}(b)$, by (E) $B(T^{\prime \prime}) \leq B(T^{\prime})$.

5. Hence, $x, y$ are siblings at depth $D$ in $T^{\prime \prime}$. Since $B(T^{\prime \prime}) \leq B(T^{\prime}) \leq B(T)$ and $T$ is optimal, $T^{\prime \prime}$ is optimal.

*** Lemma 15.3 (optimal substructure)

Let $x, y \in C$ have lowest frequencies. Let $C^{\prime} \coloneqq (C \setminus \{x, y\}) \cup \{z\}$ with $z.freq \coloneqq x.freq + y.freq$, let $T^{\prime}$ be an optimal tree for $C^{\prime}$, and let $T$ be $T^{\prime}$ with the leaf $z$ replaced by an internal node with children $x, y$. Then $T$ is optimal for $C$.

*(M) Merge.* $d_{T}(c) = d_{T^{\prime}}(c) \quad \forall c \in C \setminus \{x, y\}$, and $d_{T}(x) = d_{T}(y) = d_{T^{\prime}}(z) + 1$:

\begin{align*}
x.freq \cdot d_{T}(x) + y.freq \cdot d_{T}(y) &= (x.freq + y.freq)(d_{T^{\prime}}(z) + 1) \\
&= z.freq \cdot d_{T^{\prime}}(z) + x.freq + y.freq
\end{align*}

Hence, $B(T) = B(T^{\prime}) + x.freq + y.freq$ for every tree $T^{\prime}$ for $C^{\prime}$. Conversely, contracting two sibling leaves $x, y$ of a tree for $C$ into a leaf $z$ lowers $B$ by $x.freq + y.freq$.

*Proof.*

1. By Lemma 15.2 $\exists$ an optimal tree $T^{\prime \prime}$ for $C$ in which $x, y$ are siblings. This is the only use of $x, y$ having the lowest frequencies.

2. Let $T^{\prime \prime \prime}$ be $T^{\prime \prime}$ with the common parent of $x, y$ replaced by a leaf $z$. It is a tree for $C^{\prime}$.

3. Then,

   \begin{align*}
   B(T) &= B(T^{\prime}) + x.freq + y.freq \\
        &\leq B(T^{\prime \prime \prime}) + x.freq + y.freq \\
        &= B(T^{\prime \prime})
   \end{align*}

 As $T^{\prime \prime}$ is optimal, so is $T$.

*** Theorem 15.4

=HUFFMAN= produces an optimal prefix-free code.

*Proof.*

Induction on $n = \lvert C \rvert \geq 2$.

- $n = 2$: both leaves of the output have depth $1$, the minimum possible.

- $n > 2$: =HUFFMAN= merges the two lowest $x, y$ into $z$ (as in Lemma 15.3), then runs exactly as $\operatorname{HUFFMAN}(C')$ with $\lvert C^{\prime} \rvert = n - 1$. So its output is $T^{\prime} \coloneqq \operatorname{HUFFMAN}(C^{\prime})$ with $z$ expanded into $x, y$. $T^{\prime}$ is optimal by induction, so the output is optimal by Lemma 15.3.

** Theory

*** BST

Binary tree with $y.key \leq x.key \leq z.key$ for all $y$ in the left subtree and $z$ in the right subtree of $x$.

Storage: linked nodes with $key$, $left$, $right$, $p$ (NIL if absent); $T.root$.

*** Red-black tree

BST + $color$ per node; NIL leaves = black sentinel $T.nil$.

1. Every node is red or black.
2. Root is black.
3. Leaves (NIL) are black.
4. Red node $\implies$ both children black.
5. For each node $x$: all paths from $x$ down to a leaf have the same number of black nodes.

$\operatorname{bh}(x)$: black nodes on any path from $x$ down to a leaf ($x$ excluded, leaf counted); $\operatorname{bh}(T) \coloneqq \operatorname{bh}(T.root)$.

*** Lemma 13.1

$n$ internal (non-NIL) nodes $\implies$ height $\leq 2 \lg(n + 1)$.
