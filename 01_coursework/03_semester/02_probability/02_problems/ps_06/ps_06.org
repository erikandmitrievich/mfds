* Problem 1 :uniform_law:density:transformation:
** Task
#+begin_quote
*Conceptual.* A measurement error is modeled as $X \sim \operatorname{Unif}(-0.05, 0.05)$ millimeters. Sketch its density with labeled axes and units, verify by integration that it is normalized, and compute $f_X(0)$, $P(X = 0)$, and $P(-0.01 \leq X \leq 0.01)$. Now express the same error in micrometers as $Y = 1000X$, derive $f_Y$, and recompute the corresponding interval probability. Use the comparison to explain why density heights depend on units while probabilities do not.
#+end_quote

** Solution

\[ f_X(x) = \frac{1}{0.05 - (-0.05)} = 10 \quad \text{for } -0.05 \leq x \leq 0.05 \]

\[ \int_{-0.05}^{0.05} 10 \, dx = 10(0.05) - 10(-0.05) = 1 \]

#+begin_src python :results file link :exports both
import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(-0.08, 0.08, 1000)
y = np.where((x >= -0.05) & (x <= 0.05), 10, 0)

plt.figure(figsize=(6, 4))
plt.plot(x, y, color='blue', linewidth=2)
plt.fill_between(x, y, color='blue', alpha=0.2)

plt.title(r"Density of $X \sim \operatorname{Unif}(-0.05, 0.05)$")
plt.xlabel("Measurement Error (mm)")
plt.ylabel(r"Density (mm$^{-1}$)")
plt.ylim(0, 12)
plt.grid(True, linestyle='--', alpha=0.6)

filename = "assets/ps_01_p_01.png"
plt.tight_layout()
plt.savefig(filename)
return filename

\begin{align*}
f_X(0) &= 10 \\
P(X = 0) &= 0 \\
P(-0.01 \leq X \leq 0.01) &= \int_{-0.01}^{0.01} 10 \, dx \\
                          &= 10(0.01) - 10(-0.01) \\
                          &= 0.2
\end{align*}

Let $Y = 1000X$. The support in micrometers is $[-50, 50]$.

\[ f_Y(y) = \frac{1}{50 - (-50)} = 0.01 \quad \text{for } -50 \leq y \leq 50 \]

\begin{align*}
P(-10 \leq Y \leq 10) &= \int_{-10}^{10} 0.01 \, dy \\
                      &= 0.01(10) - 0.01(-10) \\
                      &= 0.2
\end{align*}

Probability is a dimensionless area. Changing measurement units scales the horizontal support, so the density height must scale inversely to keep the total probability area exactly $1$.

* Problem 2 :density:quantile_function:
** Task
#+begin_quote
*Mathematical.* For a constant $c > 0$, let

\[ f(x) = c(1 - x)\mathbf{1}_{[0,1]}(x) \]

Determine $c$, derive the CDF and quantile function, and calculate the \(0.9\)-quantile.
#+end_quote

** Solution

\begin{align*}
\int_{0}^{1} c(1 - x) \, dx &= 1 \\
c \left[ x - \frac{x^2}{2} \right]_{0}^{1} &= 1 \\
c \left( 1 - \frac{1}{2} \right) &= 1 \\
\frac{c}{2} &= 1 \\
c &= 2
\end{align*}

\[ f(x) = 2(1 - x)\mathbf{1}_{[0,1]}(x) \]

\[ F(x) = \begin{cases}
  0 & \text{if } x < 0 \\
  \int_{0}^{x} 2(1 - t) \, dt & \text{if } 0 \leq x \leq 1 \\
  1 & \text{if } x > 1
\end{cases} \]

\begin{align*}
\int_{0}^{x} 2(1 - t) \, dt &= \left[ 2t - t^2 \right]_{0}^{x} \\
                            &= 2x - x^2
\end{align*}

\[ F(x) = \begin{cases}
  0 & \text{if } x < 0 \\
  2x - x^2 & \text{if } 0 \leq x \leq 1 \\
  1 & \text{if } x > 1
\end{cases} \]

To find the quantile function \( Q(p) \), set \( F(x) = p \) for \( p \in (0, 1) \).

\begin{align*}
2x - x^2 &= p \\
x^2 - 2x + p &= 0
\end{align*}

\[ x = \frac{2 \pm \sqrt{4 - 4p}}{2} = 1 \pm \sqrt{1 - p} \]

Since \( x \in [0, 1] \), we must take the negative root.

\[ Q(p) = 1 - \sqrt{1 - p} \quad \text{for } 0 < p < 1 \]

\begin{align*}
Q(0.9) &= 1 - \sqrt{1 - 0.9} \\
       &= 1 - \sqrt{0.1} \\
       &\approx 0.6838
\end{align*}

* Problem 3 :simulation:memorylessness:empirical_cdf:
** Task
#+begin_quote
*Python/data.* Use ~lecture_06_examples.ipynb~ as a starting point. Simulate 30,000 independent waiting times with law $\operatorname{Exp}(2)$. Fix $s = 0.5$; retain only waits exceeding $s$, then subtract $s$ to obtain the remaining waits. Plot the empirical survival curves of the original and remaining waits together with $e^{-2t}$ for $t \geq 0$. For both samples, tabulate the empirical $0.1$, $0.5$, and $0.9$ quantiles alongside the exponential quantiles, using ~method="inverted_cdf"~ in ~np.quantile~. Report the largest absolute discrepancy from the theoretical survival curve on a stated finite grid. Repeat the survival-curve comparison for 30,000 independent waits with law $\operatorname{Unif}(0, 1)$, keeping $s = 0.5$, and derive \(P(T > s + t \mid T > s)\) for every $t \geq 0$ under that model. Explain why the two models behave differently and identify SciPy's reciprocal-rate argument.
#+end_quote

** Solution

SciPy uses the =scale= parameter for the exponential distribution, which is the reciprocal of the rate \(\lambda\). For \(\operatorname{Exp}(2)\), the argument is =scale=0.5=.

For \(T \sim \operatorname{Unif}(0, 1)\) and \(s = 0.5\), the conditional survival probability is:

\[ P(T > s + t \mid T > s) = \frac{1 - (s + t)}{1 - s} = \frac{1 - 0.5 - t}{1 - 0.5} = 1 - 2t \quad \text{for } 0 \leq t \leq 0.5 \]

The exponential model is memoryless: the remaining wait time distribution perfectly matches the fresh wait time distribution. The uniform model is not memoryless: knowing the elapsed wait time strictly reduces the maximum possible remaining wait time, altering its distribution.

import numpy as np
from scipy import stats

rng = np.random.default_rng(202606)
n_samples = 30_000
s = 0.5

# Exponential simulation
exp_dist = stats.expon(scale=0.5)
fresh_exp = exp_dist.rvs(size=n_samples, random_state=rng)
rem_exp = fresh_exp[fresh_exp > s] - s

# Quantiles
levels = [0.1, 0.5, 0.9]
q_fresh = np.quantile(fresh_exp, levels, method="inverted_cdf")
q_rem = np.quantile(rem_exp, levels, method="inverted_cdf")
q_theory = exp_dist.ppf(levels)

print("Exponential Quantiles (0.1, 0.5, 0.9):")
print(f"Theoretical:       {np.round(q_theory, 5)}")
print(f"Fresh empirical:   {np.round(q_fresh, 5)}")
print(f"Rem empirical:     {np.round(q_rem, 5)}")

# Discrepancy

    sorted_sample = np.sort(sample)
    return 1.0 - np.searchsorted(sorted_sample, thresholds, side="right") / sorted_sample.size

import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

rng = np.random.default_rng(202606)
n_samples = 30_000
s = 0.5

def empirical_survival(sample, thresholds):
    sorted_sample = np.sort(sample)
    return 1.0 - np.searchsorted(sorted_sample, thresholds, side="right") / sorted_sample.size

exp_dist = stats.expon(scale=0.5)
fresh_exp = exp_dist.rvs(size=n_samples, random_state=rng)
rem_exp = fresh_exp[fresh_exp > s] - s

unif_dist = stats.uniform(loc=0, scale=1)
fresh_unif = unif_dist.rvs(size=n_samples, random_state=rng)
rem_unif = fresh_unif[fresh_unif > s] - s

fig, axes = plt.subplots(1, 2, figsize=(10, 4))

t_grid_exp = np.linspace(0, 4, 1000)
axes[0].plot(t_grid_exp, exp_dist.sf(t_grid_exp), 'k:', linewidth=2, label="Theoretical")
axes[0].plot(t_grid_exp, empirical_survival(fresh_exp, t_grid_exp), 'b-', alpha=0.6, label="Fresh empirical")
axes[0].plot(t_grid_exp, empirical_survival(rem_exp, t_grid_exp), 'r--', alpha=0.6, label="Remaining empirical")
axes[0].set_title(r"Exponential: Memoryless")
axes[0].set_xlabel("time threshold t")
axes[0].set_ylabel("survival probability")
axes[0].legend()

t_grid_unif = np.linspace(0, 1, 500)
axes[1].plot(t_grid_unif, unif_dist.sf(t_grid_unif), 'k:', linewidth=2, label="Fresh theoretical")
axes[1].plot(t_grid_unif, np.maximum(0, 1 - 2*t_grid_unif), 'g:', linewidth=2, label="Remaining theoretical")
axes[1].plot(t_grid_unif, empirical_survival(fresh_unif, t_grid_unif), 'b-', alpha=0.6, label="Fresh empirical")
axes[1].plot(t_grid_unif, empirical_survival(rem_unif, t_grid_unif), 'r--', alpha=0.6, label="Remaining empirical")
axes[1].set_title(r"Uniform: Not Memoryless")
axes[1].set_xlabel("time threshold t")
axes[1].legend()

filename = "assets/ps_06_p_03.png"
plt.tight_layout()
plt.savefig(filename)
return filename
