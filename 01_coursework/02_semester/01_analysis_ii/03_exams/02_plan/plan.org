* Theorem lock [0/6]
Reproduce each statement verbatim, cold. These are the only theory you write out; everything else is computation.
- [ ] Fréchet derivative def + chain rule (ch_04 §4.4.1, §4.4.5). $f(x+h)=f(x)+f'(x)h+o(\|h\|)$; $(g\circ f)'=g'(f(x))f'(x)$.
- [ ] Second-order sufficient, *unconstrained* (§5.2.5). $H_f$ pos.def. → strict min; neg.def. → strict max; indefinite → saddle. Eigenvalue test allowed.
- [ ] Second-order sufficient, *constrained*. $H_{\mathcal L}$ tested *only on the tangent space* $T_xM=\{v:\nabla g(x)^\top v=0\}$. Eigenvalue shortcut fails — use the definition of definiteness.
- [ ] Lagrange corollary (§5.4.7). $\nabla f(x_0)=\sum_i \lambda_i \nabla g_i(x_0)$. Build $F:\mathbb R^{n+k}\to\mathbb R^{n+k}$ for Newton.
- [ ] Submanifold + tangent/normal (§5.4.1, §5.4.6). Regular level set, $\operatorname{rank}g'=r=n-k$; $T_x=\ker g'(x)$, $N_x=\operatorname{span}\{\nabla g_i\}$.
- [ ] Banach fixed point / local contraction (§4.4.12) + Newton iteration. $\|f'(x)\|<1$ ⇒ contraction near $x$; $X_{k+1}=X_k-J_f(X_k)^{-1}f(X_k)$.
- [ ] Newton convergence — *why* + order (added Jul 3 from lec_03/lec_04). Newton is a fixed-point iteration $\Phi(x)=x-J_f(x)^{-1}f(x)$; at a root $\Phi'(x^\ast)=0$, so §4.4.12 gives a local contraction ⇒ convergence, and $\Phi'(x^\ast)=0$ (not merely $<1$) is what upgrades it to *quadratic*. This is the "how and why Newton converges, without the IFT" the professor requires (§5.3.1). 1D sanity check: $\Phi'=f\,f''/(f')^2$, which vanishes at $f=0$.
- [ ] (Recognition only) Inverse Function Thm statement: $f'(a)$ invertible ⇒ $f$ locally invertible, $(f^{-1})'(b)=(f'(a))^{-1}$. Statement may appear in MC; the *problems* are cut.
- NB: PS05 P2's normal-equations result is a *computation*, drilled D3 — not a memorized statement, so it stays out of this list. But the Fréchet *definition* above is the lever for it.
