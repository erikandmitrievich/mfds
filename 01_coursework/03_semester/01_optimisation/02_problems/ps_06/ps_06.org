* Problem 1 :floating_point:cancellation:programming:
** Task
#+begin_quote
If bad conditioned computations are not avoidable, then put them at the beginning, NOT at the end.

The sample variance of data $x_1, \dots, x_n \in \mathbb{R}$ is

\[ \operatorname{Var}(x_1, \dots, x_n) = \frac{1}{n-1} \sum_{k=1}^{n} (x_k - \bar{x})^2, \qquad \bar{x} = \frac{1}{n} \sum_{k=1}^{n} x_k \]

This formula coincides with

\[ \operatorname{Var}(x_1, \dots, x_n) = \frac{1}{n-1} \left( \sum_{k=1}^{n} x_k^2 - \frac{1}{n} \left( \sum_{k=1}^{n} x_k \right)^2 \right) \]

a) Implement the first formula for the sample variance.

b) Implement the second formula for the sample variance.

The mean of the data

\[ \begin{aligned} x_1 &= 10{,}000{,}000.0 \\ x_2 &= 10{,}000{,}000.1 \\ x_3 &= 10{,}000{,}000.2 \end{aligned} \]

is $\bar{x} = x_2$ and the variance is $\operatorname{Var}(x_1, x_2, x_3) = 2(0.1)^2 / 2 = 0.01$.

c) Decide which formula provides the more accurate result.
#+end_quote

** Solution
*** a)

#+begin_src python :results output
def var_1(x):
    n = len(x)
    x_bar = (1 / n) * sum(x)
    s = 0

    for x_k in x:
        s += (x_k - x_bar) ** 2

    return (1 / (n - 1)) * s
#+end_src

*** b)

#+begin_src python :results output
def var_2(x):
    n = len(x)
    s = 0

    for x_k in x:
        s += x_k ** 2

    s = s - (1 / n) * (sum(x) ** 2)

    return (1 / (n - 1)) * s
#+end_src

*** c)

#+begin_src python :results output
def var_1(x):
    n = len(x)
    x_bar = (1 / n) * sum(x)
    s = 0

    for x_k in x:
        s += (x_k - x_bar) ** 2

    return (1 / (n - 1)) * s

def var_2(x):
    n = len(x)
    s = 0

    for x_k in x:
        s += x_k ** 2

    s = s - (1 / n) * (sum(x) ** 2)

    return (1 / (n - 1)) * s

x = [10000000.0, 10000000.1, 10000000.2]

print(f"var_1(x) = {var_1(x)}")
print(f"var_2(x) = {var_2(x)}\n")
print(f"var_1 deviation: {abs(var_1(x) - 0.01) / 0.01:.8%}")
print(f"var_2 deviation: {abs(var_2(x) - 0.01) / 0.01:.6%}")
#+end_src

The first formula is more accurate. In the second formula, both terms are about $3 \cdot 10^{14}$, where doubles are $0.0625$ apart, so their exact difference of $0.02$ is lost to rounding (catastrophic cancellation):

#+begin_src python :results output

x = [10000000.0, 10000000.1, 10000000.2]
a = sum(x_k ** 2 for x_k in x)
b = sum(x) ** 2 / len(x)

print(f"a     = {a}")
print(f"b     = {b}")
print(f"a - b = {a - b}  (exact: 0.02)")
print(f"spacing of doubles near a: {math.ulp(a)}")
#+end_src

#+RESULTS:
: a     = 300000006000000.0
: b     = 300000005999999.94
: a - b = 0.0625  (exact: 0.02)

The first formula subtracts first ($x_k - \bar{x}$), while the data are still nearly exact, so no information is lost.
