** Task

Describe what a heap is and what it is usually used for. Especially, talk about the following points:

(a) Explain how a heap is represented in an array.

(b) Describe the algorithms =MIN-HEAPIFY= and =BUILD-MIN-HEAP= for constructing a min heap.

(c) Explain which algorithms are needed to turn a min heap into a min priority queue, and describe the algorithm =MIN-HEAP-DECREASE-KEY=.

(d) What are the running times of =MIN-HEAPIFY= and =MIN-HEAP-DECREASE-KEY=?

** (a)

Heap is an almost complete binary tree, which satisfies min-heap property, such that each parent node is less or equal to its child nodes.

\[ \operatorname{left}(i) = 2i,\ \operatorname{right}(i) = 2i + 1,\ \operatorname{parent}(i) = \lfloor i/2 \rfloor \]

Heaps are used for priority qeueus.

** (b)

=MIN-HEAPIFY= - assumes a given nodes subtrees follow the min-heap property. Finds the minimum of parent and children values, if parent is not min, its swapped with min child. Then calls recursion on that swapped child.

=BUILD-MIN-HEAP= - finds the last internal node of a tree ($\lfloor i/2 \rfloor$), decrements this index while $i > 1$ and runs =MIN-HEAPIFY= on all internal nodes ($T[i]$).

** (c)

1. =MIN-HEAP-MINIMUM= - returns $T[1]$.

2. =MIN-HEAP-EXTRACT-MIN= - returns and removes $T[1]$, places $T[n]$ to $T[1]$, decrements $n$, runs =MIN-HEAPIFY= on $T[1]$.

3. =MIN-HEAP-DECREASE-KEY= - decrements a given node to a new value.

4. =MIN-HEAP-INSERT= - increments $n$, sets $T[n] = \infty$, decreases $T[n]$ to a new value.

=MIN-HEAP-DECREASE-KEY= - requires new key to be less than existing value, if complies, sets $T[i] = key$. While $i > 1$ and $T[\operatorname{parent}(i)] > T[i]$: swap $T[i]$ with $T[\operatorname{parent}(i)]$, set $i = \operatorname{parent}(i)$.

** (d)

Both are $O(\lg(n))$.

Bubblesort works by repeatedly swapping adjacent elements that are out of order. The procedure is

#+begin_src text
1: procedure BUBBLESORT(A, n)
2:     for i = 1 to n - 1 do
3:         for j = n downto i + 1 do
4:             if A[j] < A[j-1] then
5:                 exchange A[j] with A[j - 1]
6:             end if
7:         end for
8:     end for
9: end procedure
#+end_src

Let $A'$ denote the array $A$ after =BUBBLESORT(A, n)= is executed. To prove that =BUBBLESORT= is correct, you need to prove that it terminates and that

$$A'[1] \le A'[2] \le \cdots \le A'[n].$$

In order to show that =BUBBLESORT= actually sorts, what else do you need to prove?

State a precise loop invariant for the =for j = n downto i + 1= loop in lines 3--7 and prove that it holds.

(c) (2 points)

Using the termination condition of the loop invariant stated and proved above, state a loop invariant for the =for i = 1 to n - 1= loop in lines 2--8 that allows you to prove the inequality above for the $A'$ array.

(d) (2 points)

Prove that the loop invariant above holds and conclude that =BUBBLESORT= works.

** (a)

$A^{\prime}$ is a permutation of $A$.

** (b)

*Invariant.*

At the start of each iteration of the loop in lines 3-7: $A[j] \leq A[k]\ \forall j \leq k \leq n$

*Initialisation.*

$j = n$: $A[n] \leq A[n]$, holds trivially.

Let $A, B$ be the array before and after the iteration $i$.

Lines 4-6 make: $B[j-1] = \min(A[j - 1], A[j]),\ B[j] = \max(A[j - 1], A[j])$. $B[k] = A[k]$ otherwise.

Hence, $B[j - 1] \leq B[k]\ \forall j-1 \leq k \leq n$.

*Termination.*

$j = i$: $A[i] \leq A[k]\ \forall i \leq k \leq n$.

** Insertion sort: invariants

#+begin_src text
1: procedure INSERTION-SORT(A, n)
2:     for i = 2 to n do
3:         key = A[i]
4:         j = i - 1
5:         while j > 0 and A[j] > key do
6:             A[j + 1] = A[j]
7:             j = j - 1
8:         end while
9:         A[j + 1] = key
10:    end for
11: end procedure
#+end_src

Notation: $A_0$ is the array at the start of the current outer iteration, so $key = A_0[i]$.

*Inner invariant (lines 5-8).* At the start of each iteration:
1. $A[1 \dots j] = A_0[1 \dots j]$ (left of the hole: untouched)
2. $A[j+2 \dots i] = A_0[j+1 \dots i-1]$ (right of the hole: old block shifted right by one)
3. $A[k] > key$ for all $j+2 \leq k \leq i$

Maintenance hinges on the loop condition $A[j] > key$: line 6 moves $A_0[j]$ to position $j+1$, and it is $> key$.

*Inner termination.* $j = 0$ or $A[j] \leq key$. After line 9, $A[1 \dots i]$ is $A_0[1 \dots j]$, then $key$, then $A_0[j+1 \dots i-1]$: sorted, since both blocks are sorted and left block $\leq key <$ right block, and a permutation of $A_0[1 \dots i]$.

*Outer invariant (lines 2-10).* At the start of each iteration: $A[1 \dots i-1]$ consists of the original $A[1 \dots i-1]$ in sorted order, and $A[i \dots n]$ is unchanged.

*Outer termination.* $i = n + 1$: $A[1 \dots n]$ is the original array, sorted.
