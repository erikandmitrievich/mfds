* Problem 1 :bayes_theorem:conditional_probability:
** Task
#+begin_quote
Conceptual. A test has sensitivity 0.98 and specificity 0.95. Display the model as either a probability tree or a $2 \times 2$ probability table. Derive $\mathbb{P}(D \mid T^+)$ as a function of the prevalence $\mathbb{P}(D)$, evaluate it at $\mathbb{P}(D) = 0.01$ and $\mathbb{P}(D) = 0.50$, and use the comparison to explain both why prevalence is needed and why $\mathbb{P}(T^+ \mid D)$ cannot simply be read in the reverse direction.
#+end_quote

** Solution

Let $p \coloneqq \mathbb{P}(D)$.

|    | T⁺        | T⁻        | total |
|----+-----------+-----------+-------|
| D  | 0.98p     | 0.02p     | p     |
| Dᶜ | 0.05(1-p) | 0.95(1-p) | 1-p   |

\[ \mathbb{P}(D \mid T^+) = \frac{0.98p}{0.98p + 0.05(1-p)} \]

At $p = 0.01$ this is $0.0098/0.0593 \approx 0.165$;

at $p = 0.50$ it is $0.49/0.515 \approx 0.951$.

The test fixes only $\mathbb{P}(T^+ \mid D)$ and $\mathbb{P}(T^+ \mid D^c)$; how many positives are true depends on $p$. At $p = 0.01$, false positives ($0.0495$) outnumber true positives ($0.0098$) five to one, so $\mathbb{P}(D \mid T^+)$ is far from $\mathbb{P}(T^+ \mid D) = 0.98$.

* Problem 2 :total_probability:bayes_theorem:independence:
** Task
#+begin_quote
Mathematical.

(a) Twenty percent of incoming messages are spam. A filter flags 92% of spam messages and 3% of non-spam messages. Compute the probability that a message is flagged and the probability that a flagged message is spam.

(b) For two fair coin tosses, prove that the events /first toss is heads/, /second toss is heads/, and /the two tosses agree/ are pairwise independent but not mutually independent.
#+end_quote

** Solution
*** (a)

Let $S$ be the event that a message is spam and $F$ the event that it is flagged. By total probability and Bayes,

\begin{gather*}
\mathbb{P}(F) = 0.92 \cdot 0.2 + 0.03 \cdot 0.8 = 0.208 \\
\mathbb{P}(S \mid F) = \frac{0.184}{0.208} = \frac{23}{26} \approx 0.885
\end{gather*}

*** (b)

Take $\Omega = \{H, T\}^2$ with the uniform law, and let $A = \{HH, HT\}$ (first heads), $B = \{HH, TH\}$ (second heads), $C = \{HH, TT\}$ (agree). Each has probability $1/2$, and every intersection of two or three of them equals $\{HH\}$:

\begin{gather*}
\mathbb{P}(A \cap B) = \mathbb{P}(A \cap C) = \mathbb{P}(B \cap C) = \frac{1}{4} = \frac{1}{2} \cdot \frac{1}{2} \\
\mathbb{P}(A \cap B \cap C) = \frac{1}{4} \neq \frac{1}{8}
\end{gather*}

Hence pairwise but not mutually independent.

* Problem 3 :bayes_theorem:simulation:
** Task
#+begin_quote
Python/data. Fix sensitivity 0.95 and specificity 0.99. Across prevalences from 0.001 to 0.5, compute and plot the exact value of $\mathbb{P}(D \mid T^+)$. Determine the prevalence at which the posterior first exceeds 1/2 and mark it on the plot. At several prevalences, simulate populations and overlay the empirical fractions among positive tests. Present one low-prevalence and one high-prevalence comparison, clearly distinguishing exact probabilities from Monte Carlo estimates and explaining the discrepancy.
#+end_quote

** Solution

With prevalence $\pi$,

\[ \mathbb{P}(D \mid T^+) = \frac{0.95\pi}{0.95\pi + 0.01(1-\pi)} \]

This exceeds $1/2$ iff $\pi > \pi^* = 1/96 \approx 0.0104$:

\begin{align*}
\frac{0.95\pi}{0.95\pi + 0.01(1-\pi)} > \frac{1}{2}
  &\iff 2 \cdot 0.95\pi > 0.95\pi + 0.01(1-\pi) \\
  &\iff 0.95\pi > 0.01(1-\pi) \\
  &\iff 0.96\pi > 0.01 \\
  &\iff \pi > \frac{1}{96}
\end{align*}

#+begin_src python :results output
import numpy as np
import matplotlib.pyplot as plt

sens, spec, N = 0.95, 0.99, 10_000
ppv = lambda pi: sens * pi / (sens * pi + (1 - spec) * (1 - pi)) # positive predictive value
rng = np.random.default_rng(0)

def simulate(pi):
    D = rng.random(N) < pi
    T = rng.random(N) < np.where(D, sens, 1 - spec)
    return (D & T).sum() / T.sum(), T.sum()

sim = [0.001, 0.003, 0.01, 0.03, 0.1, 0.5]
mc = {pi: simulate(pi) for pi in sim}

grid = np.geomspace(0.001, 0.5, 500)
plt.semilogx(grid, ppv(grid), label="exact")
plt.plot(sim, [mc[pi][0] for pi in sim], "o", label=f"Monte Carlo, $N = {N}$")
plt.axvline(1 / 96, ls=":", c="gray", label=r"$\pi^* = 1/96$")
plt.xlabel(r"prevalence $\pi$")
plt.ylabel(r"$\mathbb{P}(D \mid T^+)$")
plt.legend()
plt.savefig("assets/p_03.png", dpi=150)

for pi in (0.001, 0.5):
    p, (est, m) = ppv(pi), mc[pi]
    print(f"pi = {pi}: exact {p:.4f}, MC {est:.4f}, m = {m}, SE {np.sqrt(p * (1 - p) / m):.4f}")
#+end_src

Given $m$ positives, the number of true positives is $\mathrm{Bin}(m, p)$ with $p = \mathbb{P}(D \mid T^+)$, so the estimate has standard error $\sqrt{p(1-p)/m}$. At $\pi = 0.001$, only $m = 119$ tests are positive, so the SE is $0.026$, about 30% of $p$. At $\pi = 0.5$, $m = 4902$ and the SE is $0.0015$. Both deviations are within 2 SE.
