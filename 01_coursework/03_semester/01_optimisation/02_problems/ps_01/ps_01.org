* Problem 1 :machine_numbers:floating_point:
** Task
#+begin_quote
Recall the set

\[ \mathbb{R}^{[m]} = \bigcup_{\alpha \in \mathbb{Z}} \left\{ \pm(1 + k2^{-m})2^\alpha : k = 0, 1, \dots, 2^m - 1 \right\} \cup \{0\} \]

(a) For $m = 3$, list all elements of $\mathbb{R}^{[3]}$ in $[1, 2)$ and in $[2, 4)$. What is the spacing between consecutive numbers in each interval?

(b) For arbitrary $m \geq 1$, prove that every integer $n$ with $1 \leq n \leq 2^{m+1}$ belongs to $\mathbb{R}^{[m]}$, whereas $2^{m+1} + 1$ does not.

(c) Restrict the exponent to $A \leq \alpha \leq B$, where $A, B \in \mathbb{Z}$ and $A \leq B$. Determine the number of positive elements and the smallest and largest positive values. Specialize your formulas to $m = 52$, $A = -1022$, and $B = 1023$ to obtain $r_{64}$ and $R_{64}$ from the notes.
#+end_quote

** Solution

*** (a)

Since $1 + k2^{-3} \in [1,2)$, only $\alpha = 0$ ($R_1$) and $\alpha = 1$ ($R_2$) contribute.

#+begin_src julia :results output
let
    m = 3
    k = 0:(2^m - 1)

    R_1 = (1 .+ k .* 2.0^(-m)) .* 2^0
    R_2 = (1 .+ k .* 2.0^(-m)) .* 2^1

    println("[1, 2) = [", join(R_1, ", "), "]")
    println("[2, 4) = [", join(R_2, ", "), "]")
end
#+end_src

#+RESULTS:
: [1, 2) = [1.0, 1.125, 1.25, 1.375, 1.5, 1.625, 1.75, 1.875]
: [2, 4) = [2.0, 2.25, 2.5, 2.75, 3.0, 3.25, 3.5, 3.75]

With spacing: $2^{-3}$ on $[1,2)$, $2^{-2}$ on $[2,4)$.

*** (b)

*** (c)

- *Number of positive elements:* $(B - A + 1) 2^m$ (since there are $B - A + 1$ choices for $\alpha$ and $2^m$ choices for $k$).

- *Smallest positive value:* $2^A$ (when $\alpha = A, k = 0$).

- *Largest positive value:* $(2 - 2^{-m})2^B$ (when $\alpha = B, k = 2^m - 1$).

* Problem 2 :floating_point:error_analysis:
** Task
#+begin_quote
Work in the idealized model $\mathbb{R}^{(\mathrm{eps})}$, with $0 < \mathrm{eps} < 1$. Write $\mathrm{fl} = \mathrm{fl}^{(\mathrm{eps})}$ and denote computer addition by $\oplus$.

(a) Use the axiom of computation to show that

\[ \mathrm{fl}(x) = x(1 + \delta_0), \quad a \oplus b = (a + b)(1 + \delta_1), \quad \lvert \delta_0 \rvert, \lvert \delta_1 \rvert \leq \mathrm{eps} \]

for $x \in \mathbb{R}$ and $a, b \in \mathbb{R}^{(\mathrm{eps})}$. Explain explicitly how to handle $x = 0$ and $a + b = 0$.

(b) Let $a, b, c \in \mathbb{R}^{(\mathrm{eps})}$, let $s = a + b + c \neq 0$ be the exact sum, and let $\widehat{s} = (a \oplus b) \oplus c$. Prove that

\[ \lvert \widehat{s} - s \rvert \leq \mathrm{eps} \lvert s \rvert + \mathrm{eps}(1 + \mathrm{eps}) \lvert a + b \rvert \]

(c) If $a, b, c > 0$, deduce that

\[ \frac{\lvert \widehat{s} - s \rvert}{\lvert s \rvert} \leq 2\mathrm{eps} + \mathrm{eps}^2 \]

Why does the bound in part (b) not guarantee a small relative error when $\lvert a + b + c \rvert$ is much smaller than $\lvert a + b \rvert$?

In Python, exponentiation is written **, not ^.
#+end_quote

** Solution
*** (a)

By the axiom of computation, $\lvert \operatorname{fl}(x) - x \rvert \leq \mathrm{eps} \lvert x \rvert$ for all $x \in \mathbb{R}$, and $a \oplus b = \operatorname{fl}(a + b)$.

If $x \neq 0$, set $\delta_0 \coloneqq (\operatorname{fl}(x) - x)/x$. Then $\operatorname{fl}(x) = x(1 + \delta_0)$ and $\lvert \delta_0 \rvert \leq \mathrm{eps}$.

If $x = 0$, the axiom gives $\lvert \operatorname{fl}(0) \rvert \leq 0$, so $\operatorname{fl}(0) = 0 = 0 \cdot (1 + \delta_0)$ for any $\delta_0$. Take $\delta_0 = 0$.

Applying this to $x = a + b$ gives $a \oplus b = (a + b)(1 + \delta_1)$ with $\lvert \delta_1 \rvert \leq \mathrm{eps}$, and $\delta_1 = 0$ if $a + b = 0$.

*** (b)

Let $y \coloneqq a \oplus b \in \mathbb{R}^{(\mathrm{eps})}$. By (a), $y = (a + b)(1 + \delta_1)$ and $\widehat{s} = (y + c)(1 + \delta_2)$ with $\lvert \delta_1 \rvert, \lvert \delta_2 \rvert \leq \mathrm{eps}$. Hence

\begin{align*}
\widehat{s} &= [(a + b)(1 + \delta_1) + c](1 + \delta_2) \\
            &= (a + b)(1 + \delta_1)(1 + \delta_2) + c(1 + \delta_2) && \text{(distribute } 1 + \delta_2 \text{)} \\
            &= (a + b)(1 + \delta_2) + (a + b)\delta_1(1 + \delta_2) + c(1 + \delta_2) && \text{(split } 1 + \delta_1 \text{)} \\
            &= (a + b + c)(1 + \delta_2) + (a + b)\delta_1(1 + \delta_2) && \text{(factor out } 1 + \delta_2 \text{)} \\
            &= s + s\delta_2 + (a + b)\delta_1(1 + \delta_2) && \text{(} s = a + b + c \text{)}
\end{align*}

By the triangle inequality and $\lvert 1 + \delta_2 \rvert \leq 1 + \mathrm{eps}$,

\[ \lvert \widehat{s} - s \rvert \leq \mathrm{eps} \lvert s \rvert + \mathrm{eps}(1 + \mathrm{eps}) \lvert a + b \rvert \]

*** (c)

Since $a, b, c > 0$, we have $0 < a + b < s$, so (b) gives

\[ \lvert \widehat{s} - s \rvert \leq \mathrm{eps} \lvert s \rvert + \mathrm{eps}(1 + \mathrm{eps}) \lvert s \rvert = (2\mathrm{eps} + \mathrm{eps}^2) \lvert s \rvert \]

Dividing by $\lvert s \rvert$ gives the claim.

Dividing (b) by $\lvert s \rvert$ in general gives

\[ \frac{\lvert \widehat{s} - s \rvert}{\lvert s \rvert} \leq \mathrm{eps} + \mathrm{eps}(1 + \mathrm{eps}) \frac{\lvert a + b \rvert}{\lvert s \rvert} \]

If $\lvert s \rvert \ll \lvert a + b \rvert$, the factor $\lvert a + b \rvert / \lvert s \rvert$ is large, so the bound is not small.

* Problem 3 :floating_point:programming:
** Task
#+begin_quote
The file /curiosities.ipynb/ on Moodle contains Julia snippets from the lecture. Code and observe analogous phenomena in Python by using

import numpy as np

import matplotlib.pyplot as plt

Notice that native Python and numpy deal differently with integers.
#+end_quote

** Solution

#+begin_src python :results output
import os
import numpy as np
import matplotlib.pyplot as plt

# integers: native int is unbounded, np.int64 wraps
a, b = 2**63 - 1, -2**63
print(a + 1, b - 1)
print(np.int64(a) + 1, np.int64(b) - 1)

# machine epsilon, underflow
x = 2**-52
print(5 + x == 5)
print(2**-1074, 2**-1075, 2**-1075 == 0)

# order of summation
f = lambda x, y: 4*x**4 + 2*y**2 - y**4
g = lambda x, y: 4*x**4 - y**4 + 2*y**2
print(f(13860.0, 19601.0), g(13860.0, 19601.0))

# cancellation
a = 4999999
f = lambda x: x**3 - 6*a*x**2 + 12*a**2*x - 8*a**3
g = lambda x: (x - 2*a)**3
print(f(10.0**7), g(10.0**7))

f = lambda x: 1/(x - np.sqrt(x**2 - 1))
g = lambda x: x + np.sqrt(x**2 - 1)
print(f(10**7) - g(10**7))

# ill-conditioned system
A = np.array([[1.2969, 0.8648], [0.2161, 0.1441]])
b = np.array([0.8642, 0.1440])
x = np.array([2, -2])
print(np.linalg.norm(A @ x - b))
bt = b + 1e-8 * np.array([-1, 1])
xt = np.array([0.9911, -0.4870])
print(np.linalg.norm(A @ xt - bt))

# (x - 2)^9 expanded
f = lambda x: x**9 - 18*x**8 + 144*x**7 - 672*x**6 + 2016*x**5 - 4032*x**4 + 5376*x**3 - 4608*x**2 + 2304*x - 512
g = lambda x: (x - 2)**9
x = np.linspace(1.925, 2.075, 1000)
plt.plot(x, f(x), label="f")
plt.plot(x, g(x), label="g")
plt.legend()
plt.savefig("./assets/p_03.png")
