* Problem 1 :floating_point:machine_numbers:error_analysis:
** Task
#+begin_quote
Let $\eta = r_{64} \, \mathrm{eps}_{64} = 2^{-1074}$.

(a) Show that

\[ \lvert \mathrm{fl}_{64}(x) - x \rvert \leq \frac{\eta}{2}, \qquad 0 < x < r_{64} \]

(b) Determine $\mathrm{fl}_{64}(x)$ and the relative error for $x = \frac{3}{2}\eta$ and $x = \frac{1}{2}\eta$.

(c) Check your results in Python.
#+end_quote

** Solution

*** (a)

\begin{align*}
0.f \cdot 2^{-1022} &= k \cdot 2^{-52} \cdot 2^{-1022} = k\eta, \quad k = 0, \dots, 2^{52}-1 && \text{(subnormals and } 0\text{)} \\
r_{64} &= 2^{-1022} = 2^{52}\eta \\
&\implies \mathbb{F}_{64} \cap [0, r_{64}] = \{ k\eta : k = 0, \dots, 2^{52} \} \\
x \in (0, r_{64}) &\implies x \in [k\eta, (k+1)\eta] \text{ for some } k \in \{0, \dots, 2^{52}-1\} \\
&\implies \lvert \mathrm{fl}_{64}(x) - x \rvert \leq \frac{\eta}{2} && \text{(round to nearest)}
\end{align*}

*** (b)

\begin{align*}
x_1 &= \frac{3}{2}\eta && \text{(midpoint of } \eta, 2\eta\text{)} \\
\mathrm{fl}_{64}(x_1) &= 2\eta && \text{(tie, round to even: } k = 2\text{)} \\
\varepsilon_{\text{rel}} &= \frac{\lvert 2\eta - \frac{3}{2}\eta \rvert}{\frac{3}{2}\eta} = \frac{\frac{1}{2}\eta}{\frac{3}{2}\eta} = \frac{1}{3}
\end{align*}

\begin{align*}
x_2 &= \frac{1}{2}\eta && \text{(midpoint of } 0, \eta\text{)} \\
\mathrm{fl}_{64}(x_2) &= 0 && \text{(tie, round to even: } k = 0\text{)} \\
\varepsilon_{\text{rel}} &= \frac{\lvert 0 - \frac{1}{2}\eta \rvert}{\frac{1}{2}\eta} = 1
\end{align*}

*** (c)

* Problem 2 :programming:machine_numbers:
** Task
#+begin_quote
Translate the Julia routines in Section 6.2 into Python: ~myLU~ without pivoting, then ~myLUpivot~ with partial pivoting. Also translate ~myL~ and ~myU~ for solving $L y = b$ and $U x = y$. Combine the routines to solve $Ax = b$ and test your code.
#+end_quote

** Solution

#+begin_src python :results output
import numpy as np

def myLU(A):
    n = len(A)
    L = np.eye(n)
    U = A.astype(float)
    for k in range(n - 1):
        for j in range(k + 1, n):
            L[j, k] = U[j, k] / U[k, k]
            U[j, k + 1:] -= L[j, k] * U[k, k + 1:]
            U[j, k] = 0.0
    return L, U

def myLUpivot(A):
    n = len(A)
    P = np.eye(n)
    L = np.eye(n)
    U = A.astype(float)
    for k in range(n - 1):
        p = k + np.argmax(np.abs(U[k:, k]))
        U[[k, p]] = U[[p, k]]
        P[[k, p]] = P[[p, k]]
        L[[k, p], :k] = L[[p, k], :k]
        for j in range(k + 1, n):
            L[j, k] = U[j, k] / U[k, k]
            U[j, k + 1:] -= L[j, k] * U[k, k + 1:]
            U[j, k] = 0.0
    return P, L, U

def myL(L, b):
    n = len(b)
    y = b.astype(float)
    for k in range(1, n):
        y[k] = b[k] - L[k, :k] @ y[:k]
    return y

def myU(U, y):
    n = len(y)
    x = y.astype(float)
    for k in range(n - 1, -1, -1):
        x[k] = (y[k] - U[k, k + 1:] @ x[k + 1:]) / U[k, k]
    return x

A = np.array([[2, 1, 1], [4, -6, 0], [-2, 7, 2]], dtype=float)
b = np.array([5, -2, 9], dtype=float)

L, U = myLU(A)
y = myL(L, b)
x = myU(U, y)

P, L_p, U_p = myLUpivot(A)
y_p = myL(L_p, P @ b)
x_p = myU(U_p, y_p)

print(f"{np.allclose(L @ U, A) = }")
print(f"{np.allclose(L_p @ U_p, P @ A) = }")
print(f"x (without pivoting): {x}")
print(f"x (with pivoting):    {x_p}")
#+end_src

#+RESULTS:
: np.allclose(L @ U, A) = True
: np.allclose(L_p @ U_p, P @ A) = True
: x (without pivoting): [1. 1. 2.]
: x (with pivoting):    [1. 1. 2.]

* Problem 3 :programming:machine_numbers:error_analysis:
** Task
#+begin_quote
Check the Examples 6.4.3 and 6.4.4 in Python. Increase and decrease the machine precision and change $\varepsilon$ accordingly.
#+end_quote

** Solution

$\varepsilon = 2^{-(p+2)}$ is the largest power of 2 with $\mathrm{fl}(2 - \frac{1}{\varepsilon}) = \mathrm{fl}(1 - \frac{1}{\varepsilon}) = -\frac{1}{\varepsilon}$ for a \(p\)-bit significand (the spacing below $\frac{1}{\varepsilon}$ is $2^{-p}/\varepsilon$); $p = 53$ gives the notes' $2^{-55}$.

import numpy as np
from mpmath import mp, mpf

def myLU(A):
    n = len(A)
    L = np.eye(n, dtype=A.dtype)
    U = A.copy()
    for k in range(n - 1):
        for j in range(k + 1, n):
            L[j, k] = U[j, k] / U[k, k]
            U[j, k + 1:] -= L[j, k] * U[k, k + 1:]
            U[j, k] = 0

    n = len(A)
    P = np.eye(n, dtype=A.dtype)
    L = np.eye(n, dtype=A.dtype)
    U = A.copy()
    for k in range(n - 1):
        p = k + np.argmax(np.abs(U[k:, k]))
        U[[k, p]] = U[[p, k]]
        P[[k, p]] = P[[p, k]]
        L[[k, p], :k] = L[[p, k], :k]
        for j in range(k + 1, n):
            L[j, k] = U[j, k] / U[k, k]
            U[j, k + 1:] -= L[j, k] * U[k, k + 1:]
            U[j, k] = 0
    return P, L, U

def myL(L, b):
    y = b.copy()
    for k in range(1, len(b)):
        y[k] = b[k] - L[k, :k] @ y[:k]
    return y

def myU(U, y):
    n = len(y)
    x = y.copy()
    for k in range(n - 1, -1, -1):
        x[k] = (y[k] - U[k, k + 1:] @ x[k + 1:]) / U[k, k]
    return x

mp.prec = 113  # quadruple precision; np.longdouble is just float64 on Apple Silicon

for num, p in [(np.float16, 11), (np.float32, 24), (np.float64, 53), (mpf, 113)]:

          and (y == [1, -1 / eps]).all())

            and (yp == [2, 1]).all())
    x_eps = np.array([1 / (1 - eps), (1 - 2 * eps) / (1 - eps)])
    print(f"{num.__name__}, eps = 2^-{p + 2}:")
    print(f"  6.4.3: L, U, y as in notes: {ok}, x = {x.astype(float)}")
    print(f"  6.4.4: L, U, y as in notes: {ok_p}, x = {xp.astype(float)}, x_eps = {x_eps.astype(float)}")

* Problem 4 :floating_point:programming:
** Task
#+begin_quote
Construct a strictly diagonally dominant $A \in \mathbb{R}^{3 \times 3}$ with exactly representable 64-bit entries for which ~myLU~ does produce a zero pivot. Why does this not contradict Remark 6.2.3?
#+end_quote

** Solution

\[ A = \begin{pmatrix} 1.75 & 1.5 & 0 \\ \eta & 2\eta & 0 \\ 0 & 0 & 1 \end{pmatrix}, \qquad \eta = 2^{-1074} \]

\begin{align*}
\ell_{21} &= \mathrm{fl}_{64}\left(\frac{4}{7}\eta\right) = \eta \\
\tilde{a}^{(2)}_{2,2} &= \mathrm{fl}_{64}\left(2\eta - \mathrm{fl}_{64}\left(\frac{3}{2}\eta\right)\right) = 2\eta - 2\eta = 0 && \text{(Problem 1(b))} \\
a^{(2)}_{2,2} &= 2\eta - \frac{4}{7}\eta \cdot \frac{3}{2} = \frac{8}{7}\eta \neq 0
\end{align*}

No contradiction: Remark 6.2.3 holds in exact arithmetic, but subnormal rounding errors are not bounded by $\frac{\mathrm{eps}_{64}}{2}$ (here $\frac{3}{4}$ and $\frac{1}{3}$).
